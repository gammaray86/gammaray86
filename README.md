## Избранные проекты

### 1. Прогнозирование температуры стали

**Задача:** разработать модель прогнозирования температуры стали на металлургическом производстве на основе технологических данных.

**Что сделано:**
- Объединил данные из нескольких источников, провёл исследовательский анализ и подготовку признаков.
- Обучил и сравнил несколько моделей регрессии, включая градиентные бустинги и нейронные сети.
- Разработал ансамбль из 95 нейросетей на PyTorch.
- Реализовал кэширование результатов обучения и подбора гиперпараметров с сохранением в файлы, чтобы повторно использовать результаты ресурсоёмких экспериментов.

**Результат:** MAE **5,96 °C** на тестовой выборке против **8,15 °C** у базовой модели — снижение ошибки примерно на **26,8%**.

**Инструменты:** Python, pandas, scikit-learn, PyTorch, CatBoost, LightGBM, XGBoost.

### 2. Определение возраста по фотографии

**Задача:** обучить модель компьютерного зрения для определения возраста человека по фотографии.

**Что сделано:**
- Исследовал датасет из **7591 фотографии** людей в возрасте от 1 до 100 лет, проанализировал распределение возрастов.
- Провёл эксперименты со свёрточными нейронными сетями.
- Дообучил ResNet50, исследовал влияние параметров обучения и регуляризации на качество предсказаний.

**Результат:** снижение MAE с **10,44 до 6,05 года** в ходе экспериментов с ResNet50.

**Инструменты:** Python, TensorFlow, Keras, ResNet50.

### 3. Прогнозирование заказов такси на следующий час

**Задача:** построить модель прогнозирования количества заказов такси на следующий час для планирования доступности водителей.

**Что сделано:**
- Исследовал временной ряд, выявил закономерности сезонности.
- Сформировал календарные и лаговые признаки.
- Сравнил линейную регрессию и модели градиентного бустинга.
- Использовал TimeSeriesSplit для корректной проверки моделей с учётом временной последовательности данных.
- Сравнил итоговую модель с простыми прогнозами на основе предыдущих наблюдений.

**Результат:** RMSE **34,60** на тестовой выборке — на **12,5% ниже**, чем у лучшего простого прогноза с недельным лагом (**39,55**).

**Инструменты:** Python, pandas, scikit-learn, statsmodels, CatBoost, LightGBM, XGBoost.

### 4. Мультимодальный поиск изображений по текстовому описанию

**Задача:** разработать систему поиска изображений, соответствующих текстовому запросу, с использованием совместных представлений текста и изображений.

**Что сделано:**
- Исследовал различные способы представления текстовых описаний и изображений.
- Разработал и сравнил несколько нейросетевых архитектур, включая собственную CLIP-подобную модель с контрастивным обучением.
- Провёл эксперименты по подбору архитектуры и параметров обучения.
- Сравнил собственные модели с предобученной OpenCLIP.
- Реализовал кэширование эмбеддингов, обученных моделей и результатов экспериментов для сокращения повторных вычислений.

**Результат:** MRR **0,452** у собственной CLIP-подобной модели и **0,934** у предобученной OpenCLIP на тестовой выборке.

**Инструменты:** Python, PyTorch, CLIP, OpenCLIP.

### 5. Прогнозирование снижения покупательской активности

**Задача:** разработать модель классификации для выявления клиентов интернет-магазина, у которых прогнозируется снижение покупательской активности, и исследовать факторы, связанные с этим снижением.

**Что сделано:**
- Подготовил и исследовал данные о клиентах и их покупательском поведении.
- Разработал и сравнил модели классификации, оценил качество выявления клиентов с прогнозируемым снижением активности.
- Провёл анализ влияния признаков на предсказания модели с использованием SHAP.
- Выполнил сегментацию клиентов для дальнейшего анализа их характеристик.

**Результат:** ROC-AUC **0,925** на тестовой выборке. Для класса снижения покупательской активности: **Precision 0,944**, **Recall 0,823**.

**Инструменты:** Python, pandas, scikit-learn, SHAP.
